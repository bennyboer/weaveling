# Timeline

The story is mostly linear, so a few deliberate wrinkles make it useful for tests.

## Chronological order

```
Damals im Rotkäppchen-Wald (flashback)
        │
Dienstags von 8 bis 11
        │
Warum hast du so große Augen?
        │
Formular W-3  ═══  Charlissimos Beschwerde (parallel)
        │
Strampel, Hühnerei, Wanduhr
        │
Formular U-1
```

## Wrinkles

- **Parallel scene:** while Lillynella fills out the form, Charlissimo crawls to Schalter 2 and (through the fairy) files his Dienstaufsichtsbeschwerde. Either a short extra scene or a cut within the form scene.
- **Flashback:** a short memory scene, *„Damals im Rotkäppchen-Wald"*. Chronologically before everything, narratively in the middle, so outline order ≠ timeline order.
